# VPlayer

VPlayer is a React-first video player with a framework-independent TypeScript core. The core owns playback behavior, state, source selection, event wiring, persistence, subtitles, thumbnails, hotkeys, and plugins. The React package owns rendering, controls, overlays, slots, hooks, and CSS.

Use VPlayer when a native `<video>` element is not enough, but you still want media behavior to be testable outside a single large component.

## What The Packages Do

| Package | Purpose |
| --- | --- |
| `@vplayer/core` | Creates the headless player instance, store, media engine, remote commands, event bus, storage, i18n, hotkeys, parsers, source resolver, and plugin API. |
| `@vplayer/react` | Provides `VideoPlayer`, the default UI, custom-control hooks, layouts, overlays, slots, CSS, and React-friendly re-exports from the core. |

The docs app is the public documentation and playground. It is not required by consumers.

## Main Capabilities

- Native video playback with automatic HLS and DASH engine selection from file extension or MIME type.
- A nullable engine lifecycle: the active engine is `null` before mount and after unmount.
- Safe remote commands for play, pause, seek, skip, volume, mute, playback rate, fullscreen, picture-in-picture, screenshot, loop, flip, aspect ratio, subtitles, and quality state.
- A TanStack Store-backed `MediaState` with playback, audio, preferences, UI, plugin, thumbnail, and error fields.
- WebVTT and SRT subtitle parsing helpers.
- WebVTT thumbnail previews with plain image cues and sprite cues using `#xywh=x,y,w,h`.
- Default keyboard shortcuts with an extensible `HotkeyRegistry`.
- A plugin API for registering controls, settings, layers, hotkeys, context-menu items, and notifications.
- A default React UI with controls, overlays, settings, mini-player mode, thumbnail previews, context menu, error overlay, and info panel.
- CSS variables and stable class names for app-level theming.
