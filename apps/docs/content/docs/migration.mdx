# Migration Guide

## Removed architecture pieces

VPlayer no longer needs:

```txt
packages/framework
packages/solid
skin-specific CSS entry files
```

The recommended structure is:

```txt
packages/core
packages/react
apps/docs/app/playground
apps/docs
```

## CSS migration

Before:

```tsx
import '@vplayer/react/skins/youtube.css'
```

After:

```tsx
import '@vplayer/react/player.css'
import './player-overrides.css'
```

Then override variables/classes:

```css
.vplayer {
  --vplayer-accent: #facc15;
}
```

## Mini-player migration

Mini-player is now a compact layout. Do not expect the full toolbar to appear in mini mode. Add custom compact controls only if your product truly needs them.

## Aspect ratio migration

Aspect ratio now applies only to the media viewport/video box, not the entire player shell. Unsupported persisted aspect values are normalized back to default.
