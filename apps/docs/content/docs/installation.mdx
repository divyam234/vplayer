# Installation

## App Install

Install the React package in your app:

```bash
npm install @vplayer/react
```

Then import the component and CSS:

```tsx
import { VideoPlayer } from '@vplayer/react'
import '@vplayer/react/player.css'
```

`@vplayer/react` re-exports the most useful core helpers, so normal React apps usually do not need a separate `@vplayer/core` import. Use `@vplayer/core` directly only for headless integrations, custom engines, parser utilities, or contributor work.

## Repository Install

For this repository, install workspace dependencies once:

```bash
npm install
```

Useful scripts:

```bash
npm run dev:docs       # Next.js + Fumadocs docs and /playground
npm run typecheck
npm run test
npm run build
npm run test:e2e
```

## CSS

VPlayer intentionally ships one main CSS entry:

```tsx
import '@vplayer/react/player.css'
```

Do not create a skin package for every visual style. Override the stable classes and CSS variables from your app stylesheet.

## Browser Support

VPlayer targets modern Chromium, Firefox, Safari/WebKit, iOS Safari, Android Chrome, and Edge. Browser-specific features such as fullscreen, PiP, autoplay, and media type support are detected at runtime.

HLS and DASH handling depends on browser support and the resolved media engine. Safari can play HLS natively. Other browsers use the HLS engine for `.m3u8` sources when native HLS is unavailable. DASH sources use the DASH engine.
