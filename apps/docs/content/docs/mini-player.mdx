# Mini Player

The mini-player is a compact player, not a scaled copy of the full player. In mini mode, VPlayer hides the large center overlay and full toolbar, then shows only compact controls.

## Enable mini-player

```tsx
<VideoPlayer
  src="/video.mp4"
  miniPlayer={{
    enabled: true,
    position: 'bottom-right',
    width: 360,
  }}
/>
```

You can also pass `miniPlayer={true}` to enable mini-player support with defaults.

## Auto mini-player

```tsx
<VideoPlayer
  src="/video.mp4"
  miniPlayer={{
    enabled: true,
    auto: true,
    position: 'bottom-right',
  }}
/>
```

## Compact control rules

In mini mode VPlayer keeps only:

- restore/close action
- compact play/pause
- compact seekbar
- bottom progress indicator

It hides:

- large center play/pause orb
- skip buttons
- volume panel
- settings menu
- screenshot button
- PiP button
- fullscreen button

## Edge cases

- Controls appear on pointer movement, touch, keyboard focus, and pause.
- Controls auto-hide during playback.
- The bottom progress indicator only renders in mini-player mode.
- Restore returns to the normal layout without losing player state.

## Programmatic Control

Custom controls can read and control mini-player state with `useMiniPlayer()`.

```tsx
import { useMiniPlayer } from '@vplayer/react'

function MiniToggle() {
  const miniPlayer = useMiniPlayer()

  return (
    <button type="button" onClick={miniPlayer.toggle}>
      {miniPlayer.active ? 'Restore' : 'Mini player'}
    </button>
  )
}
```

The hook exposes `enabled`, `active`, `auto`, `position`, `width`, `enter`, `exit`, and `toggle`.
