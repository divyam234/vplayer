# Getting Started

The fastest path is the React component API. Import the component and the single stylesheet, then pass a media source.

```tsx
import { VideoPlayer } from '@vplayer/react'
import '@vplayer/react/player.css'

export function WatchPage() {
  return <VideoPlayer src="/video.mp4" poster="/poster.jpg" />
}
```

## Add Captions, Qualities, And Thumbnails

Use `subtitles`, not `textTracks`. A subtitle track has `src`, `lang`, `label`, and an optional `default` flag.

```tsx
<VideoPlayer
  src="/video.mp4"
  type="video/mp4"
  poster="/poster.jpg"
  subtitles={[{ src: '/captions.en.vtt', lang: 'en', label: 'English', default: true }]}
  qualities={['Auto', '1080p', '720p', '480p']}
  thumbnails="/thumbnails.vtt"
/>
```

`qualities` is state for UI and integrations. VPlayer does not automatically swap variant URLs from those labels. Use a custom engine, plugin, or application-level source update when quality selection should load a different stream.

## Autoplay

The prop is `autoPlay`, matching React's video attribute casing. Browsers usually block autoplay with sound, so start muted through your integration layer or wait for a user gesture when needed.

```tsx
<VideoPlayer src="/video.mp4" autoPlay />
```

## Mini-Player

```tsx
<VideoPlayer
  src="/video.mp4"
  miniPlayer={{
    enabled: true,
    auto: true,
    position: 'bottom-right',
    width: 360,
  }}
/>
```

`enabled` allows mini-player mode. `auto` enters mini-player mode when the player leaves the viewport. `position` can be `bottom-right`, `bottom-left`, `top-right`, or `top-left`. `width` accepts a number of pixels or a CSS width string.

## Thumbnail Preview Tuning

```tsx
<VideoPlayer
  src="/video.mp4"
  thumbnails="/thumbnails.vtt"
  thumbnailPreview={{
    width: 180,
    height: 100,
    gap: 8,
    fit: 'cover',
    showTime: true,
  }}
/>
```

`thumbnailPreview={false}` disables seekbar thumbnail previews even when `thumbnails` is configured.

## Event Callbacks

```tsx
<VideoPlayer
  src="/video.mp4"
  onTimeUpdate={(time) => console.log(time)}
  onEnded={() => console.log('ended')}
  onError={(message) => console.error(message)}
/>
```

`onError` receives browser playback errors and blocked-playback messages from the media engine.

## CSS Overrides

VPlayer has one main stylesheet. Users can override classes and CSS variables instead of importing separate skins.

```css
.vplayer {
  --vplayer-accent: oklch(0.82 0.17 85);
  --vplayer-radius: 18px;
}

.vplayer__button {
  border-radius: 9999px;
}
```

Load your overrides after VPlayer's stylesheet.
